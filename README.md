# デルタバイパスサイト

デルタサイトのコンテンツにアクセスするためのバイパスツールです。

## 機能

- デルタサイトのコンテンツをプロキシ経由で表示
- URLの書き換えによるシームレスな閲覧体験
- コンテンツキャッシュによる高速化
- レスポンシブデザイン対応

## セットアップ

1. リポジトリをクローン
2. バックエンド依存関係をインストール: `cd backend && npm install`
3. フロントエンド依存関係をインストール: `cd frontend && npm install`
4. 環境変数を設定（必要な場合）
5. サーバーを起動: `cd backend && npm start`

## デプロイ

このアプリケーションはRenderにデプロイするように設計されています。

## 注意事項

このツールは教育目的のみで使用してください。デルタサイトの利用規約を遵守し、違法な活動には使用しないでください。
